How the value is worked out

implied value = TVL × band multiple × growth × maturity × breadth

A launch is worth a fraction of the value locked in the protocol — and the fraction shrinks as the protocol gets bigger. Growth over the last seven days moves it up or down, a longer run with no token recorded moves it up, and running on more chains moves it up. Every number below comes from the snapshot itself; no protocol is ever special-cased by name.
